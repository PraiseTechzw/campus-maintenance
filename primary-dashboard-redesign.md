# Primary Dashboard Redesign Specification

The student dashboard will shift from a simple introductory heading and three equal cards to a more intentional operations-home composition. A large **My campus care** hero will show the user's active report count, a compact service-status statement, and the main reporting action. The numerical summaries will become an overlapping mini command strip beneath the hero rather than a row of generic cards.

Recent reports will become a clearly labeled work feed with a stronger leading request card. Each card will show an issue-type color marker, a compact progress band, and a more explicit tracking action. The objective is a visibly different screen with a stronger service-desk personality while retaining the Campus Maintenance brand, accessible labels, and responsive mobile behavior.

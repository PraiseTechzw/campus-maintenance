# Campus Map, ETA, and Activity Feed Specification

The dashboard hero will use a small **abstract campus map**, drawn with interface primitives rather than copied artwork. It will include a simplified route line, campus-building blocks, and a highlighted maintenance pin; it acts as a contextual operations signal rather than a navigation map.

Active reports will display a compact ETA badge derived from the current status and urgency. Assigned reports will show an estimated technician response window, in-progress reports will show an estimated completion window, and submitted requests will show an expected review window. Resolved reports do not show an ETA.

The Activity tab will adopt the Campus Care system: a compact navy activity-summary hero, an operation-count strip, and a card-based chronological feed. The feed will make each update easier to scan using category-colour markers, action labels, report reference, time, and a visible event note when present.

# Campus Maintenance Visual Refinement Specification

The ICT dashboard will receive one distinct **Next assignment** surface. It will show the leading ICT request with ticket reference, building/location, priority, current status, and a direct action to open the work order. The surface is separate from the general queue so the technician immediately sees the next practical task.

The Security dashboard will receive an **Urgent security alert** surface only when unresolved urgent incidents exist. It will show the most urgent incident, acknowledgement state, location, and the direct action to inspect the alert. Routine security tasks remain in the standard light work queue.

The request detail will include a three-stage status rail—Submitted, Assigned, In progress—with Resolved as the completion state. It will display the current point in the workflow and pair it with a compact building/location context block.

The administrator queue will receive a **Queue lens** summary that states the active status, priority, team, and sort choices in readable language. This keeps filtering useful without forcing an administrator to mentally reconstruct the selected criteria from controls alone.

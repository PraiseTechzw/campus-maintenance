# Role Dashboard and Queue Enhancement Specification

## ICT Technician Dashboard

The ICT workspace is restricted to requests routed to the **ICT** team. Its header labels the active work queue, and the dashboard focuses on assigned technology jobs, unassigned ICT requests requiring attention, current in-progress work, and recently resolved ICT work. The primary action sends the technician to their filtered work queue rather than the campus-wide request list.

## Security Officer Dashboard

The Security workspace is restricted to **Security** requests. Urgent unresolved incidents form a dedicated alert panel at the top of the dashboard. The queue separates incidents waiting for acknowledgement from active security work, and includes only security assignments. Acknowledgement continues to be recorded in the request timeline.

## Photo Evidence

Reporters can attach one image when creating a request. The reporting screen shows a local preview and a determinate progress bar while an authenticated request is uploading. The detail screen presents the image as a tappable evidence card; tapping opens a full-screen modal with close and image-information controls.

## Administrator Queue Controls

Administrators can filter the campus-wide queue by **status**, **priority**, and **team**. They can sort the matching results by newest activity, priority, pending first, or oldest request. The active controls are visually distinct and a results count confirms the filtered working set. Non-administrator roles retain their restricted request views and do not see administrative queue controls.

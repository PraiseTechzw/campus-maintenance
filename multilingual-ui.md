# Multilingual UI Scope

Campus Maintenance will retain English as the initial language and offer **Shona** and **Ndebele** as immediate alternatives. The language control will remain available from the dashboard and profile workspace, so a user can change language without abandoning their current role or request flow.

| Interface area | English | Shona | Ndebele |
|---|---|---|---|
| Report an issue | Report an issue | Mhan'ara dambudziko | Bika uhlupho |
| Requests | Requests | Zvikumbiro | Izicelo |
| Activity | Activity | Zviitiko | Okwenzekayo |
| Profile | Profile | Nhoroondo yako | Iphrofayili |
| Resolved | Resolved | Zvagadziriswa | Kulungisiwe |
| View all | View all | Ona zvese | Bona konke |

The enhanced interface will use a consistent category-icon map, elevated request cards, compact status badges, clear priority treatments, and subtle press and entrance motion. Functional improvements will include security acknowledgement for urgent incidents, resolution feedback for students, and role-aware action panels that build on the existing assignment and completion workflow.
